# Release v0.1.0

Version v0.1.0, dated 27 October 2026, is the author-approved public artifact copy for DualRoute. The release page is https://github.com/YanZiBin/DualRoute-artifacts/releases/tag/v0.1.0. It contains the source snapshot and the original author-reviewed v2 ZIP. No DOI is assigned.

The author approved publication in this new, independent public artifact repository. The existing private research repository and its history are not included. Author-controlled code is Apache-2.0; author-controlled exported data is CC BY 4.0. Private prompts, weights and original screenshots remain withheld.

Current mobile evidence is original six complete/one partial/two unstarted plus supplemental three complete. Sessions remain separate. Private original candidates and raw records are unchanged.

The bundled `validation.json` records actual local v2 validation before publication, including historical `unpublished`, `uploaded` and `git_committed` fields. Publication changes only README.md, this document, CITATION.cff and the root SHA256SUMS.json. All application code, data and expected results remain byte-identical to the approved v2 ZIP. The public release notes record its exact archive SHA-256 and public-download checks.

The code/data license boundaries, source identities and reproduction limits accompany this release. No complete training, fresh inference, raw-image adjudication, full C++ link/build or turnkey phone reconstruction is claimed. An accessible artifact supports only the declared offline reanalyses.
