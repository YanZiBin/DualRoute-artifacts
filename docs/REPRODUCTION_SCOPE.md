# Reproduction scope

This release supports numerical reanalysis of exported observations and saved-output parser/guard replay. It does not regenerate all original experiments.

## Commands and outputs

| Command from root | Checks |
| --- | --- |
| `python -I -B analysis/verify_results.py` | 13 reference groups: system denominators/bounds, 36 charge pairs and selected t/Welch intervals, category mixtures, existing sensitivity aggregation, terminal budgets, route intervals and saved-output point metrics |
| `python -I -B mobile_admission/analysis/verify_results.py` | 12 mobile batch results, 624 planned/493 actual arrivals, branch/completion ranges, cancellation/cleanup, half-open/health and 1,762 P75 windows |

The observed cp800 labels remain 132/142 base and 129/142 variant, with complete guarded routes 121/142 and 117/142. LinearSVC labels remain 102/142 and 107/142, guarded routes 104/142 and 105/142. The generation prompt differed from production and the downstream evaluation path was corrected retrospectively using the same saved outputs; original strict results are retained in private research records. This is not new inference or a production-configuration generalization test.

The parser/guard methods are preserved; release packaging removes prompt dependencies from offline import. Research SHA identities and release-copy hashes are distinct. See `ARTIFACT_VERSIONS.md`. Missing operator prompt files must cause explicit errors in live entrypoints; no empty prompt is substituted.

## Sampling and limits

The original system benchmark has 42 distinct tasks; phone/app-state repeats do not create independent intents. Four semantic slots remain unjudgeable and 22 timeouts are retained. Energy units are active-idle pairs, three per condition, 36 total; intervals are exploratory, with outliers preserved. Category mixtures are conditional interpolation, not measured current Mixed workloads. Historical Mixed uses other units/configurations and stays separate.

The sensitivity command reaggregates 144 existing fixed-input cells; it does not rerun or optimize a detector. Budget recounts hold measured outcomes fixed and keep missing timings, recovered timings and caps separate. Router host intervals include preparation/communication/parsing/evidence; they exclude startup, reset, later actions and visible TTFA.

The synthetic set has 142 paired groups, 284 consumed texts and shared action families. Labels were AI authored/reviewed without independent human adjudication. Example email addresses use reserved `example.invalid`. The text is not a semantic-family holdout and is preserved unchanged.

Mobile observations are separated by session: original six complete/one partial/two unstarted; supplemental three complete. Busy/refusal/reset/cap/verification/unknown outcomes remain. Availability exposures after degradation cannot prove availability-triggered entry from Normal. No author-assisted captcha rerun is supplied. Native timing, controller arrival timing and cleanup occupancy have different origins.

Stored bootstrap uncertainty and historical Mixed summaries remain reference results; not every stored interval is regenerated by the verifier. No training, fresh cp800/LinearSVC inference, full original experiment, original sensor reconstruction, complete figure rebuild, screenshot re-adjudication, visible TTFA or additional energy measurement is verified. No public weights, training-data rights or turnkey device source are asserted.

Private prompts, original screenshots, accounts, endpoints, devices, original reset/control context and unopened holdouts are excluded. Anonymous source hashes are provenance, not public downloads or independent proof of label correctness. Actual/matched continuous networks are unavailable.
